# Steam store page of AI SLOP ARENA

Everything to paste into Steamworks lives in the repo, is generated by scripts and is checked against
the game itself. Talk to the user in French. Commit after each step that changes files (memory
"commit-each-step"), staging explicit paths only: other sessions work in this repo at the same time.

## Where things are

| Path | What | Made by |
| --- | --- | --- |
| `steam/store/<lang>.md` | One page per Steam language (30): name, short description, About This Game (BBCode), AI disclosure, achievements, system requirements | Hand-written `en.md`, translated by agents |
| `steam/store/README.md` | The launch guide for the user (settings, tags, visuals, pricing, calendar, checklist), in French | Hand-written |
| `steam/store/extras/*.gif` | The 3 GIFs of the description (616 px wide) | ffmpeg, see below |
| `steam/store/check.py` | Checks every page against the rules and the game | - |
| `steam/store/preview.mjs` | Builds `preview.html`, a local mock-up of the Steam page (git-ignored) | - |
| `steam/achievements/<ID>.jpg`, `<ID>_locked.jpg` | Achievement icons 256x256 | `art-src/gen_achievements.py` |
| `steam/capsules/*` | Every capsule and library image Steamworks asks for | `art-src/gen_capsules.py` |
| `steam/store/trailer.mp4` | 1080p trailer with music and logo intro (git-ignored, 64 MB) | `art-src/make_steam_trailer.py` |
| `steam/README.md` | Steamworks technical setup (app id, stats, achievements API names, SteamPipe) | Hand-written |

The game is the source of truth: achievements come from `src/achievements.js`, their names and every
translated game term from `src/i18n/en.js` and `src/i18n/locales/<lang>.json`.

## Content rules (Valve review and the user's choices)

- **Page structure** (the preview and the checker parse it): a `# ` title, one note line, then exactly
  six `## ` sections in this order: game name, short description, About This Game, AI disclosure,
  achievements table, system requirements table. Sections 1 to 4 each hold one code block.
- **Short description**: 300 characters max.
- **No AI-looking typography** anywhere: no em dash, no en dash, no typographic quotes (« » „ “ ” ‘ ’),
  no ellipsis character, no arrows. Use plain `"` and `'`. Rephrase instead of dashing, even in
  Russian and Ukrainian. CJK pages use their native punctuation and 「」. Only the achievements table
  is exempt: it copies the game's strings word for word.
- **AI is mentioned only in the mandatory AI disclosure section**, kept short and generic (what was
  generated, directed and tested by a human, nothing generated live). No "made by AI" section in the
  description, no development time, no prompt count, no asset cost: the user wants Valve to accept
  the game, so it must not read as rushed.
- **Never mention Brawl Stars, Supercell or "Showdown"**, not even in tags.
- Brawler names (Blaster, Gunslinger, Bomber, Frostbite, Volt) and "AI SLOP ARENA" stay in English;
  arena names, achievements and game words ("brawler", power cubes, super, match) use the game's own
  translation of that language.
- Describe the brawlers as they are in the game today (read `brawler.<key>.desc` in the locales and
  `src/brawler.js`), not from memory: they get redesigned.

## Task: update the texts

1. Edit `steam/store/en.md` first (source of truth for wording).
2. Propagate to the 29 other pages. Small change (a sentence, a list item): patch every file with a
   Python script written with the Write tool (memory "patch-scripts-via-write": bash heredocs break on
   long multilingual text and backslashes). Big change: re-translate with parallel agents, 5 or 6
   languages each (it pt pt-BR es-419 nl / sv da no fi pl / cs hu ro bg el / tr ru uk ar th /
   vi id ja ko zh-CN zh-TW), each told: the structure above, the rules above, reuse
   `src/i18n/locales/<code>.json` for achievements (`ach.<ID>`, `ach.<ID>.desc`), arena names
   (`map.oasis|dunes|grove|frost|marsh`) and game words, native idiomatic store copy, count the short
   description with Python, write UTF-8 LF, touch no other file.
3. `python steam/store/check.py` must print `0 with errors`.
4. `node steam/store/preview.mjs`, then look at it (see Preview).

When the game gains a **language**, add its page (the checker warns about missing ones) and a row to
the language table of `steam/store/README.md` (Steamworks language name in English).

## Task: achievements

The list is `ACHIEVEMENTS` in `src/achievements.js`; `steam/README.md` holds the API names and stats
to declare in Steamworks. When one is added or renamed:

1. Check its strings exist in `src/i18n/en.js` and every locale (`ach.<ID>`, `ach.<ID>.desc`).
2. Add a row to the achievements table of every page, copying the game strings (the checker compares).
3. Add its prompt to `ICONS` in `art-src/gen_achievements.py` (background colour + one bold object,
   no text), then `python art-src/gen_achievements.py <ID>` (about $0.006 per icon). It writes the raw
   1024 image to `art-src/achievements/` and the unlocked + locked 256 JPGs to `steam/achievements/`.
   Look at the result; regenerate if it resembles a known character or brand (it happened: Mickey's
   gloves).

Image model notes: `openai/gpt-image-2.5-sunburst` through OpenRouter only works on
`POST https://openrouter.ai/api/v1/images` (`{model, prompt, size, n}` -> `data[0].b64_json`), not on
chat/completions. Sizes 1024x1024, 1536x1024, 1024x1536. It **ignores reference images** and
invents look-alikes of other games' mascots (Astro Bot, Fall Guys): never ask it to draw our brawlers.
Key: env `OPENROUTER_API_KEY`, else the genere-assets skill key (see the scripts).

## Task: capsules and library art

`python art-src/gen_capsules.py` rebuilds everything in `steam/capsules/`: the model paints only the
empty arena backgrounds (`art-src/capsules/bg_wide.png`, `bg_tall.png`, generated once), then the
script composites the real brawler cut-outs (`art-src/chibi/cut_action/<key>.png`) and the real logo
(`docs/readme/logo.png`). `--regen wide` or `--regen tall` redraws a background.

- If a brawler is redesigned or added, refresh its cut-out first (see memory "character-art-prompts"),
  update `GROUP` in the script, rebuild.
- Valve rules: capsules show only artwork and the logo (no "free", no score, no award, no quote); the
  library hero has no logo and no text; the library logo is a transparent PNG.
- Sizes: header 920x430, small 462x174, main 1232x706, vertical 748x896, page background 1438x810,
  library capsule 600x900, library header 920x430, library hero 3840x1240, library logo 1280x720,
  community icon 184x184.
- Always open the results and look for halos, cut-off brawlers or banding before committing.

## Task: description GIFs

616 px wide, under ~3 MB each, from the trailer and the site screenshots:

```bash
S=public/assets/site; O=steam/store/extras
ffmpeg -y -ss 0.5 -t 3 -i $S/trailer.mp4 -vf "fps=10,scale=616:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=64:stats_mode=diff[p];[b][p]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle" $O/battle.gif
```

`weather.gif` and `daynight.gif` crossfade stills (`feat_weather/storm/fog/light.jpg`,
`tod_0..3.jpg`) with `xfade` into the same palette chain. Their names are referenced by every page.

## Task: trailer

`python art-src/make_steam_trailer.py` renders `steam/store/trailer.mp4` (1080p30 H.264 + AAC) from the
frames `.ai3d/capture/trailer/f*.jpg` recorded by `src/trailer.js`, with `battle.mp3` starting so that
its drop (11.15 s into the track) lands on the logo: "AI", "SLOP", "ARENA" slam in on the music's
accents, the logo comes back at the end. Record new frames first if the game changed visually.
Steam wants gameplay from the first second (the logo sits over gameplay, no title card) and 30 to 60 s
ideally; the current one is 25 s.

## Preview

```bash
node steam/store/preview.mjs
```

Then `preview_start` with the `steam-preview` configuration of `.claude/launch.json` (a Python static
server on port 8790) and open `http://localhost:8790/steam/store/preview.html`. The language bar
switches between the 30 pages; it uses the real header capsule and trailer when they exist. The
server has no HTTP range support, so seeking in the video fails; playing works. Screenshot the page for
the user after a change.
