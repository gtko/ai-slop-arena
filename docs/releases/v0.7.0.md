**Crash reports, game statistics and a quick "Having fun?".** The game now tells us when it breaks, how it runs on your device and what you think of it, so every next patch fixes the right things. No account, no name, no IP address, no ads, and you can turn each one off.

> ✅ No forced update: 0.6.x still plays online with 0.7.0.

## ✨ Highlights

<p align="center"><img src="https://raw.githubusercontent.com/gtko/ai-slop-arena/main/docs/releases/img/v0.7.0-feedback.png" alt="Crash reports, game statistics and the Having fun? survey" width="100%"></p>

### 🐞 Crash reports
- When the game or the online server hits an error, the error and where it happened are sent automatically, with the game version, platform and graphics chip. Many bugs can now be fixed before anyone reports them.
- The in-game bug report (F8) is linked to the crash it follows, so both are read together.
- On the server, a match whose simulation fails now ends cleanly instead of freezing the room.

### 📊 Game statistics
- Which brawlers win, which maps are played or left early, how long the matchmaking queue takes, and the frame rate during matches on every kind of device.
- They drive the next balance changes and the graphics tuning for slow devices.

### 😍 Having fun?
- After some matches, the result screen asks how much fun you are having (five faces) and, if you like, what would make the game better. At most once a month.

### 🔒 Your choice
- Two switches in **Options > General**: crash reports and game statistics, each on by default and off in one click. A link to the privacy policy sits right below.
- Everything is tied only to the random ID of your device; your IP address is not kept and not used to locate you. Details in the [privacy policy](https://ai-slop-arena.gtux-prog.workers.dev/privacy).
- New texts in all 30 languages.
