**A second client, same arena.** A native Godot 4 client joins the repository as a preview: it plays in the same matches as the web, Steam and mobile players, and looks like the game you know. The web game gets a few readability fixes.

## ✨ Highlights

<p align="center"><img src="https://raw.githubusercontent.com/gtko/ai-slop-arena/main/docs/releases/img/v0.17.0-changes.png" alt="Godot 4 client preview, looks like the web game, a live match on the home screen, keyboard gamepad and touch, Android and web builds, easier to read on the web" width="100%"></p>

### 🧪 Godot 4 client (preview)
- A thin client of the same server: it draws the server's matches and sends your inputs, so it **plays with everyone** online (cross-play with the web, Steam, Epic and mobile builds).
- Same home screen with a **live bot match behind it** (96 matches recorded from the real server rules, replayed offline), same lighting, water and shores, projectiles, HUD, shop, collection and options.
- Keyboard (rebindable, AZERTY works), full gamepad support, touch controls; Windows, Linux, Android and web exports, built by CI. How to run it: [`godot/README.md`](https://github.com/gtko/ai-slop-arena/blob/main/godot/README.md).
- It is a preview: it is not part of the downloads below yet.

### 👀 Easier to read on the web
- A price you can't pay now sits on dark glass, in the shop and on a locked brawler's unlock panel (pale text on the gold button was unreadable).
- The key hints under SUPER and the gadget, the touch SUPER label and the move stick get an ink outline: readable on sand and snow.
