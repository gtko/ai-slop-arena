# Stránka obchodu Steam: čeština

Vložte do Steamworks (Store Page Admin > Description) pod jazykem "Čeština".

## Název hry

```
AI SLOP ARENA
```

## Krátký popis (max. 300 znaků)

```
Roztomilá rvačka pro osm hráčů s pohledem shora. Vyber si rváče, schovej se ve vysoké trávě, rozbíjej bedny kvůli kostkám síly a vydrž jako poslední, zatímco se stahuje jedovatý plyn. Pět arén s živým počasím a střídáním dne a noci. Hraj sólo proti botům nebo online s přáteli.
```

## Informace o obsahu generovaném AI (dotazník k obsahu)

Předem vygenerovaný obsah: **ano**. Obsah generovaný za běhu: **ne**.

```
Veškerý obsah hry (kód, grafika, 3D modely, hudba, zvukové efekty) byl před vydáním vygenerován pomocí AI pod vedením člověka, který ho otestoval a schválil. Během hraní hra žádný obsah pomocí AI negeneruje.
```
