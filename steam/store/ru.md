# Страница в Steam: русский

Вставьте в Steamworks (Store Page Admin > Description), язык "Русский" (Russian).

## Название игры

```
AI SLOP ARENA
```

## Краткое описание (не более 300 символов)

```
Милый бравлер с видом сверху для восьми игроков. Выберите бойца, прячьтесь в высокой траве, ломайте ящики ради кубов силы и останьтесь последним, когда сомкнётся ядовитый газ. Пять арен с живой погодой и сменой дня и ночи. Играйте в одиночку против ботов или онлайн с друзьями.
```

## Об игре (BBCode)

```
[img]{STEAM_APP_IMAGE}/extras/battle.gif[/img]

[h2]Побеждает последний выживший[/h2]
Восемь бойцов высаживаются на арену. Прячьтесь в высокой траве, ломайте ящики ради кубов силы, которые делают вас сильнее, и не стойте на месте: ядовитый газ сжимается. Уйти отсюда сможет только один.

[h2]Пять бойцов, пять стилей боя[/h2]
[list]
[*][b]Blaster[/b]: голем-пень, чей мушкетон из бревна бьёт веером из пяти колючих семян вблизи. Супер: взрыв, который отбрасывает врагов и крушит стены.
[*][b]Gunslinger[/b]: аксолотль, звёздный рейнджер, чьи два лучевых пистолета дают дальнюю очередь из шести лучей. Супер: залп из двенадцати лучей, прошивающий стены насквозь.
[*][b]Bomber[/b]: магмовый бесёнок, забрасывающий огненные шары через укрытия. Супер: метеорит, сносящий всё вокруг.
[*][b]Frostbite[/b]: три ледяных осколка, замедляющих врагов. Супер: морозная волна, замораживающая всех поблизости.
[*][b]Volt[/b]: сфера, молния которой перескакивает на двух врагов. Супер: гроза, обрушивающая молнии с неба.
[/list]

[img]{STEAM_APP_IMAGE}/extras/weather.gif[/img]

[h2]Пять арен, пять видов погоды[/h2]
[list]
[*][b]Оазис[/b]: ясное небо и водоёмы.
[*][b]Буря в дюнах[/b]: песчаная буря проносится над дюнами.
[*][b]Дождливая роща[/b]: дождь, гром и молнии.
[*][b]Ледяной пик[/b]: снегопад и скользкий лёд.
[*][b]Туманное болото[/b]: туман, сокращающий обзор до нескольких метров.
[/list]
В каждом матче также случайно выбирается время суток: утро, полдень, закат или ночь. С наступлением сумерек зажигаются фонари, а за вами следует налобный фонарик, отбрасывая вперёд длинные тени.

[h2]Играйте с друзьями[/h2]
Создайте лобби и пригласите друзей из Steam или позвольте им присоединиться прямо из списка друзей. Матчи идут напрямую между игроками (P2P) через Steam: никаких серверов и проброса портов. Свободные места занимают боты, а в одиночку против ботов можно играть всегда.

[img]{STEAM_APP_IMAGE}/extras/daynight.gif[/img]

[h2]Особенности[/h2]
[list]
[*]Матчи на 8 игроков до последнего выжившего: в одиночку против ботов или онлайн.
[*]5 бойцов, у каждого основная атака и супер.
[*]5 арен с погодой, которая меняет игру: лёд, туман, песчаная буря, дождь.
[*]Освещение и тени в реальном времени, смена дня и ночи, свечение (bloom) и фоновое затенение (ambient occlusion).
[*]15 достижений Steam.
[*]Мышь и клавиатура или геймпад, переназначаемые клавиши.
[*]Пресеты графики от "Низкое" до "Ультра": игра идёт даже на скромных ПК.
[/list]
```

## Раскрытие информации о контенте, созданном ИИ (опрос о контенте)

Заранее сгенерированный контент: **да**. Контент, генерируемый в реальном времени: **нет**.

```
Весь контент игры (код, графика, 3D-модели, музыка, звуковые эффекты) был создан с помощью ИИ до релиза под руководством человека, который его тестировал и утверждал. Во время игры никакой ИИ-контент не генерируется.
```

## Достижения

| Имя API | Название | Описание |
| --- | --- | --- |
| `FIRST_KO` | Первая кровь | Выведите из строя бойца. |
| `FIRST_WIN` | Последний герой | Выиграйте матч. |
| `RAMPAGE` | Буйство | Выведите из строя 3 бойцов за один матч. |
| `POWER_HUNGRY` | Жажда силы | Наберите 8 кубов силы за один матч. |
| `ONLINE_WIN` | Любимец публики | Выиграйте онлайн-матч против живого игрока. |
| `SQUAD_UP` | Банда в сборе | Сыграйте онлайн-матч с другом. |
| `WORLD_TOUR` | Мировое турне | Сыграйте на всех пяти аренах. |
| `JACK_OF_ALL` | Мастер на все слопы | Выиграйте матч каждым из пяти бойцов. |
| `VETERAN` | Ветеран | Сыграйте 25 матчей. |
| `CENTURION` | Центурион | Выведите из строя 100 бойцов. |
| `PODIUM` | На пьедестале | Займите место в тройке лучших. |
| `SUPER_KO` | Супердобивание | Выведите из строя бойца суперударом. |
| `NIGHT_OWL` | Ночная сова | Выиграйте матч ночью. |
| `CRATE_CRUSHER` | Крушитель ящиков | Сломайте 50 ящиков. |
| `CHAMPION` | Чемпион | Выиграйте 10 матчей. |

| | Минимальные | Рекомендуемые |
| --- | --- | --- |
| ОС | Windows 10 64-бит | Windows 10/11 64-бит |
| Процессор | Двухъядерный 2,5 ГГц (Intel Core i3 / AMD Ryzen 3) | Четырёхъядерный 3 ГГц (Intel Core i5 / AMD Ryzen 5) |
| Оперативная память | 4 ГБ ОЗУ | 8 ГБ ОЗУ |

| Сеть | Широкополосное подключение к интернету (для онлайн-игры) | Широкополосное подключение к интернету |
| Место на диске | 1 ГБ свободного места | 1 ГБ свободного места |
| Дополнительно | Одиночная игра против ботов работает без подключения к интернету. | |
