# Strona sklepu Steam: polski

Wklej każdy blok do odpowiedniego pola w Steamworks (Store Page Admin > Description), język "Polish".

## Nazwa gry

```
AI SLOP ARENA
```

## Krótki opis (maks. 300 znaków)

```
Urocza bijatyka z widokiem z góry dla ośmiu graczy. Wybierz zadymiarza, ukryj się w wysokiej trawie, rozbijaj skrzynki, by zdobyć kostki mocy, i przetrwaj do końca, gdy trujący gaz się zacieśnia. Pięć aren z żywą pogodą oraz cyklem dnia i nocy. Graj solo z botami lub online ze znajomymi.
```
