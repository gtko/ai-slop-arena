# Steam áruházi oldal: magyar

Illeszd be a Steamworksbe (Store Page Admin > Description) a "Magyar" nyelvnél.

## A játék neve

```
AI SLOP ARENA
```

## Rövid leírás (legfeljebb 300 karakter)

```
Aranyos, felülnézetes bunyós játék nyolc játékosnak. Válassz harcost, bújj el a magas fűben, törd a ládákat erőkockákért, és maradj utolsóként talpon, miközben szűkül a mérges gáz. Öt aréna élő időjárással és napszakváltással. Játssz egyedül botok ellen vagy online a barátaiddal.
```

## MI által generált tartalom közzététele (tartalmi kérdőív)

Előre generált tartalom: **igen**. Élőben generált tartalom: **nem**.

```
A játék teljes tartalma (kód, grafika, 3D modellek, zene, hangeffektusok) a megjelenés előtt MI segítségével készült, egy ember irányításával, aki tesztelte és jóváhagyta. Játék közben semmilyen MI-tartalom nem generálódik.
```
