# Σελίδα Steam: Ελληνικά

Επικόλληση στο Steamworks (Store Page Admin > Description), γλώσσα "Ελληνικά".

## Όνομα παιχνιδιού

```
AI SLOP ARENA
```

## Σύντομη περιγραφή (έως 300 χαρακτήρες)

```
Ένα χαριτωμένο brawler με κάμερα από ψηλά για οκτώ παίκτες. Διάλεξε μαχητή, κρύψου στα ψηλά χόρτα, σπάσε κιβώτια για κύβους δύναμης και μείνε ο τελευταίος όρθιος καθώς κλείνει το δηλητηριώδες αέριο. Πέντε αρένες με ζωντανό καιρό και κύκλο μέρας/νύχτας. Παίξε σόλο με bots ή online με φίλους.
```

[h2]Παίξε με φίλους[/h2]

## Γνωστοποίηση περιεχομένου που δημιουργήθηκε με ΤΝ (ερωτηματολόγιο περιεχομένου)

Προδημιουργημένο περιεχόμενο: **ναι**. Περιεχόμενο που δημιουργείται ζωντανά: **όχι**.

```
Όλο το περιεχόμενο του παιχνιδιού (κώδικας, γραφικά, 3D μοντέλα, μουσική, ηχητικά εφέ) δημιουργήθηκε με ΤΝ πριν από την κυκλοφορία, υπό την καθοδήγηση ενός ανθρώπου που το δοκίμασε και το ενέκρινε. Το παιχνίδι δεν δημιουργεί κανένα περιεχόμενο με ΤΝ ενώ παίζεις.
```

## Επιτεύγματα

| Όνομα API | Όνομα | Περιγραφή |
| --- | --- | --- |
| `FIRST_KO` | Πρώτο αίμα | Βγάλε νοκ άουτ έναν μαχητή. |
| `FIRST_WIN` | Ο τελευταίος όρθιος | Κέρδισε έναν αγώνα. |
| `RAMPAGE` | Αμόκ | Βγάλε νοκ άουτ 3 μαχητές σε έναν αγώνα. |
| `POWER_HUNGRY` | Δίψα για δύναμη | Κράτα 8 κύβους δύναμης σε έναν αγώνα. |
| `ONLINE_WIN` | Ο αγαπημένος του κοινού | Κέρδισε έναν online αγώνα απέναντι σε άλλον άνθρωπο. |
| `SQUAD_UP` | Η παρέα μαζεύτηκε | Παίξε έναν online αγώνα με έναν φίλο. |
| `WORLD_TOUR` | Παγκόσμια περιοδεία | Παίξε και στις πέντε αρένες. |
| `JACK_OF_ALL` | Πολυτεχνίτης του slop | Κέρδισε έναν αγώνα με καθέναν από τους πέντε μαχητές. |
| `VETERAN` | Βετεράνος | Παίξε 25 αγώνες. |
| `CENTURION` | Εκατόνταρχος | Βγάλε νοκ άουτ 100 μαχητές. |
| `PODIUM` | Στο βάθρο | Τερμάτισε έναν αγώνα στην πρώτη τριάδα. |
| `SUPER_KO` | Σούπερ τελείωμα | Βγάλε νοκ άουτ έναν μαχητή με το σούπερ σου. |
| `NIGHT_OWL` | Νυχτοπούλι | Κέρδισε έναν αγώνα τη νύχτα. |
| `CRATE_CRUSHER` | Σπάστης κιβωτίων | Σπάσε 50 κιβώτια. |
| `CHAMPION` | Πρωταθλητής | Κέρδισε 10 αγώνες. |
