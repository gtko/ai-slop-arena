## ゲーム名

```
AI SLOP ARENA
```

## 短い説明（最大300文字）

```
8人で遊べる、かわいい見下ろし型のバトルアクション。ブロウラーを選んで草むらに隠れ、箱を壊してパワーキューブを集め、迫りくる毒ガスの中で最後の1人まで生き残れ！天候が刻々と変わる5つのアリーナと昼夜サイクルを搭載。Bot相手のソロプレイも、フレンドとのオンライン対戦も楽しめます。
```
