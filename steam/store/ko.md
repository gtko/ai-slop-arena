```
AI SLOP ARENA
```

## 짧은 설명 (최대 300자)

```
8명이 즐기는 귀여운 탑다운 난투 게임. 브롤러를 골라 수풀에 숨고, 상자를 부숴 파워 큐브를 모으고, 좁혀 오는 독가스 속에서 최후의 1인으로 살아남으세요. 실시간 날씨와 낮밤 주기가 살아 있는 아레나 5곳. 봇을 상대로 솔로로, 또는 친구와 온라인으로 즐겨 보세요.
```

## AI 생성 콘텐츠 공개 (콘텐츠 설문)

사전 생성 콘텐츠: **예**. 실시간 생성 콘텐츠: **아니요**.

```
게임의 모든 콘텐츠(코드, 그래픽, 3D 모델, 음악, 효과음)는 출시 전에 AI로 생성되었으며, 한 사람이 제작을 지휘하고 직접 테스트하여 승인했습니다. 게임을 플레이하는 동안에는 AI 콘텐츠를 전혀 생성하지 않습니다.
```
