# Steam-Shopseite: Deutsch

In Steamworks (Store Page Admin > Description) unter der Sprache "Deutsch" einfügen.

## Spielname

```
AI SLOP ARENA
```

## Kurzbeschreibung (max. 300 Zeichen)

```
Ein niedlicher Top-down-Brawler für acht Spieler. Wähle einen Brawler, versteck dich im hohen Gras, zerschlag Kisten für Power-Würfel und bleib als Letzter stehen, während sich das Giftgas schließt. Fünf Arenen mit Live-Wetter und Tag-Nacht-Zyklus. Solo gegen Bots oder online.
```

## Über das Spiel (BBCode)

```
[img]{STEAM_APP_IMAGE}/extras/battle.gif[/img]

[h2]Wer zuletzt steht, gewinnt[/h2]
Acht Brawler landen in der Arena. Versteck dich im hohen Gras, zerschlag Kisten und sammle Power-Würfel, die dich stärker machen, und bleib in Bewegung: Das Giftgas rückt näher. Nur einer kommt wieder heraus.

[h2]Fünf Brawler, fünf Kampfstile[/h2]
[list]
[*][b]Blaster[/b]: ein Baumstumpf-Golem, dessen Donnerbüchse aus einem Stamm fünf Dornensamen auf kurze Distanz verschießt. Super: eine Druckwelle, die Gegner zurückstößt und Mauern zertrümmert.
[*][b]Gunslinger[/b]: ein Axolotl-Sternenranger, dessen zwei Strahlenpistolen eine Salve aus sechs Strahlen auf große Distanz feuern. Super: zwölf Strahlen, die durch Mauern gehen.
[*][b]Bomber[/b]: ein Magma-Kobold, der Feuerbälle über Deckungen wirft. Super: ein Meteor, der alles in der Umgebung dem Erdboden gleichmacht.
[*][b]Frostbite[/b]: drei Eissplitter, die verlangsamen. Super: eine Frostnova, die alle in der Nähe einfriert.
[*][b]Volt[/b]: eine Kugel, deren Blitz auf zwei Gegner überspringt. Super: ein Gewitter, das Blitze einschlagen lässt.
[/list]

[img]{STEAM_APP_IMAGE}/extras/weather.gif[/img]

[h2]Fünf Arenen, fünf Wetterlagen[/h2]
[list]
[*][b]Oase[/b]: klarer Himmel und Wasserbecken.
[*][b]Dünensturm[/b]: ein Sandsturm fegt über die Dünen.
[*][b]Regenhain[/b]: Regen, Donner und Blitze.
[*][b]Frostgipfel[/b]: Schneefall und rutschiges Eis.
[*][b]Nebelsumpf[/b]: Nebel, der deine Sicht auf wenige Meter schrumpfen lässt.
[/list]
Jede Runde bekommt außerdem eine Tageszeit: Morgen, Mittag, Sonnenuntergang oder Nacht. Nach der Dämmerung gehen die Laternen an und eine Stirnlampe folgt dir und wirft lange Schatten voraus.

[h2]Spiel mit Freunden[/h2]
Erstelle eine Lobby und lade deine Steam-Freunde ein, oder lass sie direkt über die Freundesliste beitreten. Die Runden laufen Peer-to-Peer über Steam: kein Server, keine Portweiterleitung. Freie Plätze werden mit Bots aufgefüllt, und du kannst jederzeit solo gegen Bots spielen.

[h2]Features[/h2]
[list]
[*]Runden für 8 Spieler nach dem Last-One-Standing-Prinzip, solo gegen Bots oder online.

[*]5 Arenen, deren Wetter das Spiel verändert: Eis, Nebel, Sandsturm, Regen.
[*]Echtzeit-Beleuchtung und -Schatten, Tag-Nacht-Zyklus, Bloom und Ambient Occlusion.
[*]15 Steam-Errungenschaften.
[*]Maus und Tastatur oder Controller, frei belegbare Tasten.
[*]Grafik-Presets von Niedrig bis Ultra: läuft auch auf einfachen PCs.
```

## Errungenschaften

| API-Name | Name | Beschreibung |
| --- | --- | --- |
| `FIRST_KO` | Erstes Blut | Knocke einen Brawler aus. |
| `FIRST_WIN` | Einer bleibt übrig | Gewinne ein Match. |
| `RAMPAGE` | Randale | Knocke 3 Brawler in einem Match aus. |
| `POWER_HUNGRY` | Machthungrig | Halte 8 Power-Würfel in einem Match. |
| `ONLINE_WIN` | Publikumsliebling | Gewinne ein Online-Match gegen einen anderen Menschen. |
| `SQUAD_UP` | Gemeinsam stark | Spiele ein Online-Match mit einem Freund. |
| `WORLD_TOUR` | Welttournee | Spiele in allen fünf Arenen. |
| `JACK_OF_ALL` | Hans Dampf in allen Slops | Gewinne ein Match mit jedem der fünf Brawler. |
| `VETERAN` | Veteran | Spiele 25 Matches. |
| `CENTURION` | Zenturio | Knocke 100 Brawler aus. |
| `PODIUM` | Aufs Treppchen | Beende ein Match unter den Top 3. |
| `SUPER_KO` | Super-Finish | Knocke einen Brawler mit deinem Super aus. |
| `NIGHT_OWL` | Nachteule | Gewinne ein Match bei Nacht. |
| `CRATE_CRUSHER` | Kistenknacker | Zerstöre 50 Kisten. |
| `CHAMPION` | Champion | Gewinne 10 Matches. |
