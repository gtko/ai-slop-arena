# Страница в Steam: български

Поставете в Steamworks (Store Page Admin > Description), език "Български".

## Име на играта

```
AI SLOP ARENA
```

## Кратко описание (до 300 знака)

```
Симпатичен екшън с изглед отгоре за осем играчи. Избери боец, скрий се във високата трева, чупи сандъци за кубове сила и остани последният оцелял, докато отровният газ се затваря. Пет арени с динамично време и смяна на деня и нощта. Играй соло срещу ботове или онлайн с приятели.
```

## Оповестяване на генерирано от ИИ съдържание (въпросник за съдържанието)

Предварително генерирано съдържание: **да**. Съдържание, генерирано в реално време: **не**.

```
Цялото съдържание на играта (код, графика, 3D модели, музика, звукови ефекти) е генерирано с ИИ преди издаването, под ръководството на човек, който го е тествал и одобрил. Играта не генерира никакво съдържание с ИИ, докато играеш.
```

## Постижения

| API име | Име | Описание |
| --- | --- | --- |
| `FIRST_KO` | Първа кръв | Нокаутирай боец. |
| `FIRST_WIN` | Последен оцелял | Спечели мач. |
| `RAMPAGE` | Вилнеене | Нокаутирай 3 бойци в един мач. |
| `POWER_HUNGRY` | Жаден за сила | Събери 8 куба сила в един мач. |
| `ONLINE_WIN` | Любимец на публиката | Спечели онлайн мач срещу друг човек. |
| `SQUAD_UP` | Бандата е тук | Изиграй онлайн мач с приятел. |
| `WORLD_TOUR` | Световно турне | Играй на всичките пет арени. |
| `JACK_OF_ALL` | Майстор на всички слопове | Спечели мач с всеки от петте бойци. |
| `VETERAN` | Ветеран | Изиграй 25 мача. |
| `CENTURION` | Центурион | Нокаутирай 100 бойци. |
| `PODIUM` | На подиума | Завърши мач в топ 3. |
| `SUPER_KO` | Супер финал | Нокаутирай боец със супера си. |
| `NIGHT_OWL` | Нощна птица | Спечели мач през нощта. |
| `CRATE_CRUSHER` | Трошач на сандъци | Счупи 50 сандъка. |
| `CHAMPION` | Шампион | Спечели 10 мача. |
