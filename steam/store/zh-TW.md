## 遊戲名稱

```
AI SLOP ARENA
```

## 簡短說明（最多 300 個字元）

```
一款可愛的俯視角八人亂鬥遊戲。挑選英雄、躲進草叢、打破箱子收集能量方塊，在不斷逼近的毒霧中撐到最後。五座競技場，搭配即時天氣與日夜循環。可以單人挑戰機器人，也能和好友線上揪團開打。
```

[list]

[*][b]Gunslinger[/b]：雙持射線槍的六角恐龍星際遊俠，遠距離六連發。超級技能：貫穿牆壁的十二發齊射。
[*][b]Bomber[/b]：越過掩體丟火球的熔岩小惡魔。超級技能：把周圍一切夷為平地的隕石。
[*][b]Frostbite[/b]：射出三枚能緩速敵人的冰晶。超級技能：凍結附近所有人的冰霜新星。
[*][b]Volt[/b]：射出電球，閃電會連鎖到兩名敵人。超級技能：召喚落雷的雷暴。

建立大廳並邀請 Steam 好友，或讓他們直接從好友清單加入。對戰透過 Steam 點對點連線進行：不需要伺服器，也不用設定連接埠轉發。空位會由機器人補上，你也隨時可以單人挑戰機器人。

[h2]AI 花兩個晚上做出來的遊戲[/h2]
名副其實。AI SLOP ARENA 是由 AI 模型 Claude Opus 5.5 在 Claude Code 中自主完成，只花了兩個晚上：它撰寫程式碼、生成美術、親自試玩測試，並修好出問題的地方。插圖、材質、音樂與音效全都由 AI 生成，3D 公仔則是在一台家用電腦上根據這些插圖建模而成。幕後的人類寫了 35 個提示詞，並在醜的時候說一句「好醜」。素材總花費：2.61 美元。

[*]5 座競技場，天氣會改變玩法：冰面、濃霧、沙塵暴、降雨。
[*]即時光影、日夜循環、光暈與環境光遮蔽。

[*]畫質預設從「低」到「極高」：中低階電腦也能順暢執行。

## AI 生成內容揭露（內容問卷）

預先生成的內容：**是**。即時生成的內容：**否**。

```
遊戲的所有內容（程式碼、美術、3D 模型、音樂、音效）皆於發行前由 AI 生成，並由一名人類負責指導、測試與審核。遊玩期間不會即時生成任何 AI 內容。
```
