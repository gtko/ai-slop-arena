# Сторінка в Steam: українська

Вставте в Steamworks (Store Page Admin > Description), мова "Українська" (Ukrainian).

## Назва гри

```
AI SLOP ARENA
```

## Короткий опис (не більше 300 символів)

```
Милий бравлер із видом згори для восьми гравців. Оберіть бійця, ховайтеся у високій траві, трощіть ящики заради кубів сили й залиштеся останнім, коли зімкнеться отруйний газ. П'ять арен із живою погодою та зміною дня і ночі. Грайте самі проти ботів або онлайн із друзями.
```

## Розкриття інформації про контент, створений ШІ (опитування щодо контенту)

Попередньо згенерований контент: **так**. Контент, що генерується в реальному часі: **ні**.

```
Увесь контент гри (код, графіку, 3D-моделі, музику, звукові ефекти) було створено за допомогою ШІ до релізу під керівництвом людини, яка його тестувала та затверджувала. Під час гри жоден ШІ-контент не генерується.
```

## Досягнення

| Ім'я API | Назва | Опис |
| --- | --- | --- |
| `FIRST_KO` | Перша кров | Виведіть з ладу бійця. |

| `POWER_HUNGRY` | Жага сили | Зберіть 8 кубів сили за один матч. |
| `ONLINE_WIN` | Улюбленець публіки | Виграйте онлайн-матч проти живого гравця. |

| `WORLD_TOUR` | Світове турне | Зіграйте на всіх п'яти аренах. |
| `JACK_OF_ALL` | Майстер на всі слопи | Виграйте матч кожним із п'яти бійців. |
| `VETERAN` | Ветеран | Зіграйте 25 матчів. |
| `CENTURION` | Центуріон | Виведіть з ладу 100 бійців. |
| `PODIUM` | На п’єдесталі | Займіть місце в трійці найкращих. |
| `SUPER_KO` | Супердобивання | Виведіть з ладу бійця суперударом. |
| `NIGHT_OWL` | Нічна сова | Виграйте матч уночі. |
| `CRATE_CRUSHER` | Трощитель ящиків | Розбийте 50 ящиків. |
| `CHAMPION` | Чемпіон | Виграйте 10 матчів. |
