# Steam-kauppasivu: suomi

Liitä jokainen lohko vastaavaan kenttään Steamworksissa (Store Page Admin > Description), kieli "Finnish".

## Pelin nimi

```
AI SLOP ARENA
```

## Lyhyt kuvaus (enintään 300 merkkiä)

```
Söpö ylhäältä kuvattu tappelupeli 8 pelaajalle. Valitse tappelija, piiloudu korkeaan heinikkoon, riko laatikoita voimakuutioiden toivossa ja jää viimeiseksi pystyyn, kun myrkkykaasu sulkeutuu. Viisi areenaa, elävä sää ja vuorokausirytmi. Pelaa yksin botteja vastaan tai verkossa kavereiden kanssa.
```

## Tekoälyn tuottaman sisällön ilmoitus (sisältökysely)

Ennalta tuotettu sisältö: **kyllä**. Reaaliaikaisesti tuotettu sisältö: **ei**.

```
Kaikki pelin sisältö (koodi, grafiikka, 3D-mallit, musiikki, äänitehosteet) tuotettiin tekoälyllä ennen julkaisua. Työtä ohjasi ihminen, joka testasi ja hyväksyi sen. Peli ei tuota tekoälysisältöä pelatessasi.
```
