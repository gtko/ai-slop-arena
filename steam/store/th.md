# หน้าร้านค้า Steam: ภาษาไทย

วางลงใน Steamworks (Store Page Admin > Description) ในภาษา "ไทย" (Thai)

## ชื่อเกม

```
AI SLOP ARENA
```

## คำอธิบายสั้น (ไม่เกิน 300 ตัวอักษร)

```
เกมบรอว์เลอร์สุดน่ารักมุมมองจากด้านบนสำหรับผู้เล่นแปดคน เลือกนักสู้ ซ่อนตัวในพงหญ้าสูง ทุบลังเก็บพาวเวอร์คิวบ์ แล้วเป็นคนสุดท้ายที่รอดขณะแก๊สพิษบีบเข้ามา ห้าสนามพร้อมสภาพอากาศสดและวัฏจักรกลางวันกลางคืน เล่นเดี่ยวกับบอทหรือออนไลน์กับเพื่อนก็ได้
```

## การเปิดเผยเนื้อหาที่สร้างด้วย AI (แบบสำรวจเนื้อหา)

เนื้อหาที่สร้างไว้ล่วงหน้า: **ใช่** เนื้อหาที่สร้างแบบเรียลไทม์: **ไม่ใช่**

```
เนื้อหาทั้งหมดของเกม (โค้ด งานภาพ โมเดล 3D เพลง เสียงเอฟเฟกต์) สร้างด้วย AI ก่อนวางจำหน่าย ภายใต้การกำกับของมนุษย์ที่ทดสอบและอนุมัติทุกอย่าง เกมไม่ได้สร้างเนื้อหาด้วย AI ใดๆ ระหว่างที่คุณเล่น
```

## ความสำเร็จ

| ชื่อ API | ชื่อ | คำอธิบาย |
| --- | --- | --- |
| `FIRST_KO` | เลือดแรก | น็อกเอาต์นักสู้ 1 คน |
| `FIRST_WIN` | คนสุดท้ายที่รอด | ชนะการแข่ง 1 ครั้ง |
| `RAMPAGE` | อาละวาด | น็อกเอาต์นักสู้ 3 คนในการแข่งเดียว |
| `POWER_HUNGRY` | กระหายพลัง | ถือพาวเวอร์คิวบ์ 8 ลูกในการแข่งเดียว |
| `ONLINE_WIN` | ขวัญใจมหาชน | ชนะการแข่งออนไลน์ที่มีผู้เล่นจริงคนอื่น |
| `SQUAD_UP` | รวมแก๊ง | เล่นออนไลน์กับเพื่อน 1 ครั้ง |
| `WORLD_TOUR` | ทัวร์รอบโลก | เล่นครบทั้งห้าสนาม |
| `JACK_OF_ALL` | เซียนสลอปทุกสาย | ชนะการแข่งด้วยนักสู้ทั้งห้าคน คนละครั้ง |
| `VETERAN` | ทหารผ่านศึก | เล่น 25 แมตช์ |
| `CENTURION` | ร้อยศพ | น็อกเอาต์นักสู้ 100 คน |
| `PODIUM` | ขึ้นโพเดียม | จบแมตช์ใน 3 อันดับแรก |
| `SUPER_KO` | ปิดฉากด้วยซูเปอร์ | น็อกเอาต์นักสู้ด้วยท่าซูเปอร์ |
| `NIGHT_OWL` | นกฮูกราตรี | ชนะการแข่งตอนกลางคืน |
| `CRATE_CRUSHER` | นักทุบลัง | ทุบลัง 50 ใบ |
| `CHAMPION` | แชมป์ | ชนะ 10 แมตช์ |
